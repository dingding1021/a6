基础玩法教学

从一棵树开始，一步步活过第一夜，再到建造属于自己的基地。

生存模式 10 个知识卡 零基础友好

01第一夜生存时间线

  1. 0~2 分钟｜撸树：长按左键收集 4~6 个原木。
  2. 2~4 分钟｜做工作台：原木 → 木板 → 4 木板合成工作台。
  3. 4~8 分钟｜做木镐：木板 + 木棍，挖 3 个石头升级石镐。
  4. 8~12 分钟｜找煤或烧木炭：做火把，保证基地周围亮度充足。
  5. 12~15 分钟｜造简易庇护所：挖山洞或用泥土围一个 3×3 小屋。
  6. 15 分钟+｜做床：3 羊毛 + 3 木板，右键睡觉跳过夜晚并设置重生点。
⏰ 游戏内一天约 20 分钟（白天 10 分钟、夜晚 7 分钟、黄昏黎明各 1.5 分钟）。看到天空变橙就该回家了。

09新手常见问题

为什么我挖不动黑曜石？
黑曜石需要钻石镐或下界合金镐才能破坏，且挖掘时间较长（约 9.4 秒）。用水浇在岩浆源上可以生成黑曜石。
床为什么不能睡觉？
可能是：① 附近有怪物（半径 8 格内）；② 不是夜晚或雷雨；③ 床周围没有足够空间。另外在下界和末地使用床会爆炸。
怎么快速回家？
记录基地坐标后，使用 /tp 玩家名 X Y Z（需开启作弊）；或在床上睡一觉，死亡后会重生在床边。
死了之后物品会消失吗？
物品会掉落原地，5 分钟内未被拾取就会消失。掉落物所在区块如果被卸载，计时会暂停。建议随身携带一个箱子或用「死亡坐标」记录。
如何获得经验最快？
前期挖煤矿石、烧炼物品；中后期建造刷怪塔、刷末影人塔，或大量交易村民。

代码教学

用命令和 NBT，让世界完全按你的想法运转。从一条 /give 到完整的数据包，这里都有。

命令系统 NBT / JSON 数据包 进阶必学

01命令基础语法

  • 在聊天框输入以 / 开头的内容，就是一条命令。
  • 通用结构：/命令 <目标> <参数>，尖括号内为必填，方括号内为可选。
  • 坐标写法：~ ~ ~ 表示相对当前位置，^ ^ ^ 表示朝向相对。
  • 数字后缀 1.5、d、s 分别代表倍数、天、秒。
  • 开启作弊：创建世界时勾选「允许作弊」，或在服务器 server.properties 中设置 enable-command-block=true。
// 一条最简单的命令：给自己 64 个钻石
/give @p diamond 64

02目标选择器

选择器含义
@p最近的玩家
@r随机一名玩家
@a所有玩家
@s命令执行者自己
@e所有实体（含生物、掉落物、盔甲架）
@n最近的实体（1.21+）

常用筛选参数

// 距离 10 格内的所有僵尸
@e[type=zombie,distance=..10]

// 20 格内、手持钻石剑的玩家
@a[distance=..20,nbt={SelectedItem:{id:"minecraft:diamond_sword"}}]

// 名字叫 Bubu 的玩家
@a[name="Bubu"]

// 分数 kills 大于等于 10 的玩家
@a[scores={kills=10..}]

// 排除旁观者模式
@a[gamemode=!spectator]

04进阶：/execute 条件执行

/execute 是命令系统里最强大的工具，由「子命令链」组成：

// 把执行者脚下的方块换成红石块
/execute at @s run setblock ~ ~-1 ~ redstone_block

// 给 10 格内所有僵尸点上火（Fire:200 = 10 秒）
/execute as @e[type=zombie,distance=..10] run data merge entity @s {Fire:200}

// 只有手持钻石剑的玩家才会被传送到大厅
/execute as @a[nbt={SelectedItem:{id:"minecraft:diamond_sword"}}] run tp @s 0 64 0

// 如果玩家在 Y=100 以上，就给他发光效果
/execute as @a at @s if entity @s[y=100,dy=200] run effect give @s glowing 10 0 true

// 检测脚下是否为草方块
/execute if block ~ ~-1 ~ grass_block run say 你站在草地上！
🧠 记忆口诀：as 改执行者，at 改坐标，if 做判断，run 后接真正的命令。

05NBT 数据基础

NBT 是《我的世界》用来存储物品、实体、方块附加数据的格式，本质是键值对。

// 一把 5 级锋利 + 3 级耐久的钻石剑
/give @p diamond_sword{Enchantments:[{id:"sharpness",lvl:5},{id:"unbreaking",lvl:3}]} 1

// 一个自定义名字的盔甲架
/summon armor_stand ~ ~ ~ {CustomName:'"Bubu"'}

// 一个带发光效果的僵尸
/summon zombie ~ ~ ~ {Glowing:1b}

// 修改最近实体的生命值
/data merge entity @e[limit=1,sort=nearest] {Health:20f}

// 查看方块数据
/data get block ~ ~-1 ~
⚠️ 修改前先用 /data get 查看现有数据，避免覆盖出错。测试请务必在创造模式的测试存档里进行。

06tellraw 与 JSON 文本

用 JSON 可以做出彩色、可点击、带悬停提示的聊天信息。

// 一条金色加粗的公告
/tellraw @a {"text":"欢迎来到服务器！","color":"gold","bold":true}

// 可点击的传送按钮
/tellraw @a [
  {"text":"["},
  {"text":"点击传送回主城","color":"aqua","bold":true,
   "clickEvent":{"action":"run_command","value":"/tp @s 0 64 0"},
   "hoverEvent":{"action":"show_text","contents":"把你传送到出生点"}},
  {"text":"]"}
]

// 标题与副标题
/title @a title {"text":"第一章","color":"blue"}
/title @a subtitle {"text":"初入方块世界"}

07计分板 scoreboard

// 新建一个计分项（击杀数）
/scoreboard objectives add kills playerKillCount "击杀数"

// 显示在右侧边栏
/scoreboard objectives setdisplay sidebar kills

// 手动给玩家加分
/scoreboard players add Bubu kills 1

// 设置分数 / 重置
/scoreboard players set Bubu kills 0

// 在下方显示一个自定义计分板
/scoreboard objectives add money dummy "金币"
/scoreboard objectives setdisplay list money
💰 计分板是经济系统、任务系统、成就系统的基础，几乎所有服务器玩法都会用到它。

08命令方块

  • 获取方式：/give @p command_block
  • 界面：右键打开，输入命令后点击「完成」保存。
  • 三种类型：脉冲（红石触发一次）、循环（持续执行，可设延迟）、连锁（跟随前一个执行）。
  • 条件：无条件 / 有条件（前一个方块执行成功才运行）。
  • 自动执行：循环方块设为「保持开启」，即可无需红石持续运行。
// 循环 + 无条件 + 保持开启 = 每 20 tick（1 秒）执行一次
/say 欢迎来到 LaBubu 服务器！

// 连锁方块：接在上一条后面，做后续动作
/effect give @a regeneration 5 0 true

09数据包 Datapack

数据包可以让你把一批命令打包成「函数」，实现复杂逻辑而不用堆一堆命令方块。

你的世界/datapacks/hello/
├── pack.mcmeta
└── data/
    └── hello/
        └── function/
            ├── load.mcfunction
            └── tick.mcfunction

pack.mcmeta 内容

{
  "pack": {
    "pack_format": 15,
    "description": "LaBubu 教学示例数据包"
  }
}

tick.mcfunction（每 tick 自动执行）

# 每 tick 给所有玩家 1 秒饱和效果
effect give @a saturation 1 0 true

# 每 tick 检测玩家是否到达 Y=200
execute as @a at @s if entity @s[y=200,dy=100] run title @s title "你飞得太高啦！"
📦 加载方式：把文件夹放进存档的 datapacks 目录，然后在游戏中执行 /reload。

10学习路线建议

  1. 第 1 周：熟悉 /give、/tp、/setblock、/fill 等基础命令。
  2. 第 2 周：掌握目标选择器与 /execute。
  3. 第 3 周：学习 NBT 与 /data，能自定义物品与实体。
  4. 第 4 周：用命令方块搭出第一个小游戏（如跑酷计时）。
  5. 进阶：学习数据包，把命令组织成函数与标签。
  6. 再进阶：接触服务器插件（Bukkit / Spigot）或模组开发（Fabric / Forge）。

02经典红石装置

  • 自动门：压力板 + 红石粉 + 活塞，玩家靠近自动开门。
  • 隐藏楼梯：粘性活塞推动方块，实现地下入口。
  • 自动农场：观察者检测作物成熟 → 触发活塞收割 → 漏斗矿车收集。
  • 刷怪塔：高空平台 + 水流集中 + 漏斗收集，稳定产出经验与掉落物。
  • 自动熔炉组：漏斗进料，另一侧漏斗回收成品，可串联成 8 连炉。
  • 红石时钟：中继器环形连接，产生固定频率脉冲，用于定时器。
  • 甘蔗机 / 竹子机：观察者检测生长，活塞一键收割。
🔧 建造红石装置时，先在地面上用创造模式测试，确认逻辑无误后再搬到生存存档。

03附魔全解

附魔台周围摆满 15 个书架（距离 2 格，中间留空），可获得最高 30 级附魔。

05下界速通流程

  1. 准备 10 个黑曜石 + 打火石，搭建 4×5 下界传送门。
  2. 进入下界后先记坐标，防止迷路。
  3. 寻找 下界要塞，击杀烈焰人获取 烈焰棒（需要 6 根以上）。
  4. 在 诡异森林 或 灵魂沙峡谷 击杀末影人，收集末影珍珠。
  5. 在 Y≈15 层挖掘 远古残骸，用床或 TNT 爆破效率更高。
  6. 将远古残骸烧成下界合金碎片，与金锭合成下界合金锭，升级装备。
🔥 在下界不要乱放床！床在下界与末地会爆炸，是双刃剑。防具记得带抗火药水。

06末地与末影龙攻略

  • 开启传送门：12 个末影之眼放入传送门框架的 12 个凹槽（注意朝向）。
  • 末地结构：黑曜石平台 + 末地石岛 + 10 座黑曜石柱（顶部有末影水晶）。
  • 第一阶段：先破坏所有末影水晶（可以用弓射，或搭柱子近战）。
  • 第二阶段：末影龙会俯冲，站在柱子下躲避；在龙栖息处放床，等它落下时右键引爆（经典速通技巧）。
  • 第三阶段：击杀后进入折跃门，通过末地城获得 鞘翅 与 潜影贝。
🪂 鞘翅 + 烟花火箭是后期最快的赶路方式，配合「耐久 III + 经验修补」几乎不会损坏。

07自动化与效率

  • 刷怪塔：建在海洋或高空，利用刷怪机制集中掉落。
  • 村民交易大厅：多个图书管理员同时交易，刷附魔书效率极高。
  • 全自动农场：小麦、胡萝卜、马铃薯、甘蔗、竹子都能自动化。
  • 钓鱼机：AFK 挂机即可获得附魔书、命名牌等稀有物品。
  • 铁傀儡农场：村民集中 + 水流收集，稳定产出铁锭。
  • 经验熔炉：大量烧炼物品，集中领取经验。

08PVP 与战斗技巧

  • 走位：对拼时保持侧向移动，让对方难以瞄准。
  • 盾牌：右键举盾可格挡正面伤害，注意被斧头击中会短时间失效。
  • 暴击：跳跃下落时攻击会造成 1.5 倍伤害。
  • 弓箭：蓄力满弓伤害最高，预判对手落点。
  • 末影珍珠：快速位移，但会造成 5 点摔落伤害。
  • 药水：力量、速度、抗火、瞬间治疗都是 PVP 必备。
  • 金苹果：对拼时吃金苹果可以瞬间回血并提升抗性。

09建筑与地形改造

  • 搭脚手架：用沙子或泥土快速搭高，方便建造大型建筑。
  • 地形笔刷：创造模式下用 /fill 快速平整或挖掘地形。
  • 对称建筑：先搭一侧，再用 /clone 镜像复制。
  • 光影与材质包：安装 Shader 可大幅提升画面质感（需 OptiFine 或 Iris）。
  • 建筑参考：先从 9×9 的小屋练起，逐步扩大规模。

11高手小技巧合集

  • 落地前一瞬间倒水，可以完全免除摔落伤害。
  • 船可以在冰上高速滑行，也可以用来「船跳」上高处。
  • 末影珍珠能快速位移，配合摔落保护效果更安全。
  • 在下界用床炸远古残骸，效率远高于手动挖。
  • 把铁傀儡放在村庄边缘，可以持续产出铁锭。
  • 用命名牌给生物命名，可以防止它被自然清除。
  • 把物品放进潜影盒，可以大幅节省背包空间。
